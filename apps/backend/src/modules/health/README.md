# Health module

## Назначение

Предоставляет минимальный endpoint проверки доступности backend-приложения.

## Контракт

`GET /health`

Ответ `200`:

```json
{
  "status": "ok"
}
```

## Правила

- Endpoint не обращается к базе данных и внешним сервисам.
- Тест контроллера является обязательным smoke-тестом приложения.
- Readiness-проверки инфраструктурных зависимостей будут добавлены отдельным контрактом, чтобы не смешивать liveness и readiness.
