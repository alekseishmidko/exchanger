# Contracts

Единый закрытый слой команд и событий между модулями биржи.

## Правила использования

- Импортировать контракты можно только из `@exchange/contracts`.
- Запрещён импорт внутренних файлов пакета через `@exchange/contracts/src/...`.
- Контракты не должны содержать бизнес-логику и зависимости от NestJS, БД или транспорта.
- Входящие сообщения проходят runtime validation через Zod-схему.
- Денежные значения, цены и количества передаются decimal-строками.
- Каждая схема имеет `messageType` и `messageVersion`.
- Поля нельзя удалять, переиспользовать с другим смыслом или менять тип без новой версии контракта.
- Новые необязательные поля должны быть backward-compatible.
- Breaking change требует нового типа/версии, migration plan и contract tests.

## Содержимое

- `src/common.ts` — envelope и общие примитивы;
- `src/commands.ts` — команды пользователя;
- `src/events.ts` — доменные события;
- `src/index.ts` — единственная публичная точка экспорта;
- `test/` — тесты совместимости и runtime validation.

Подробные правила версионирования описаны в [ADR 0002](../../docs/adr/0002-contract-layer.md).
